# CompTIA A+ — Module 1: Hardware & The Helpdesk Trenches

## Hardware & The Helpdesk Trenches

A+ is the rite of passage. It's the trench warfare of IT. This is where you learn how to handle a motherboard without frying it with static electricity, how to differentiate DDR4 from DDR5 RAM, and how to revive a completely dead Windows machine using nothing but a USB stick and sheer willpower.

The core of A+ troubleshooting is the **CompTIA Troubleshooting Methodology**. Memorize it like a religious text:
1. Identify the problem (Question the user, check logs).
2. Establish a theory of probable cause (Occam's razor—start with the obvious).
3. Test the theory to determine the cause.
4. Establish a plan of action to resolve the problem and implement the solution.
5. Verify full system functionality and implement preventive measures.
6. Document findings, actions, and outcomes.

**⚓ Anchor:** The six-step troubleshooting methodology is a pilot's pre-flight checklist, not a suggestion — it exists because panicked improvisation is how a 5-minute fix becomes a 3-hour outage. A junior tech skips straight to “reinstall Windows.” A CompTIA-certified tech identifies the problem, forms a theory, tests it cheaply first, and only then commits to the nuclear option.

**Exam Tip (A+):** When a scenario gives you multiple valid-sounding fixes, pick whichever matches the CURRENT step in the methodology, not the fix that would ultimately work. If the scenario is still at “establish a theory,” the answer is a diagnostic action, not a repair action.
